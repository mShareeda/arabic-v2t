# صَوت — تفريغ صوتي متعدد اللهجات العربية

تطبيق ويب يحوّل الكلام إلى نص **أثناء نطقه**، باللهجة التي يتحدّث بها المستخدم فعلًا
(البحرينية/الخليجية، المصرية، الفصحى، الإنجليزية)، مع طبقة تنظيف تحذف كلمات الحشو
والتلعثم تلقائيًا — وهي ميزة لا يوفّرها أي محرك تفريغ تجاري.

## البدء السريع

```bash
pnpm install
cp .env.example .env          # اضبط AUTH_SECRET على الأقل
pnpm --filter @arabic-v2t/db generate
pnpm --filter @arabic-v2t/db migrate
pnpm dev                      # الواجهة على :3000 وخادم البث على :4000
```

**بلا مفتاح API؟** يعمل التطبيق كاملًا. حين يكون `SPEECHMATICS_API_KEY` فارغًا يشتغل
محرك وهمي يبثّ نصًا تجريبيًا محشوًّا بكلمات الحشو عمدًا، فترى طبقة التنظيف وهي تعمل
دون صرف دقيقة واحدة.

## البنية

```
apps/web       واجهة Next.js 15 + مسارات REST + المصادقة
apps/gateway   خادم Fastify للبث الحي — يحمل مفتاح المحرك ويفرض الحصص
packages/core  سجل اللهجات + طبقة التنظيف (منطق نقي، بلا شبكة)
packages/db    مخطط Prisma وعميل قاعدة البيانات
```

خادم البث **خدمة مستقلة** لأن الاستضافة المشتركة (ومنها خطة Hostinger الحالية)
لا تدعم اتصالات WebSocket طويلة الأمد. تفاصيل النشر في
[`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md).

## إضافة لهجة جديدة

خطوتان، ولا شيء غيرهما:

**١.** أنشئ `packages/core/src/dialects/levantine.ts`:

```ts
export const levantine: DialectDefinition = {
  id: 'ar-LB',
  label: 'الشامية',
  description: 'لبنان، سوريا، الأردن، فلسطين',
  sample: 'كيفك؟ شو أخبارك؟',
  family: 'levantine',
  direction: 'rtl',
  flag: '🇱🇧',
  engine: {
    speechmatics: {
      language: 'ar',
      operatingPoint: 'enhanced',
      maxDelay: 1.5,
      additionalVocab: ['بيروت', 'كيفك', 'هلق'],
    },
    google: { languageCode: 'ar-LB', model: 'chirp_3' },
    whisper: { language: 'ar', initialPrompt: 'محادثة باللهجة الشامية.' },
  },
  fillers: ['اه', 'امم', 'يعني', 'شو'],
  protectedWords: [{ word: 'شو', keepWhen: /شو\s+(?:أخبارك|بدك|صار)(?![؀-ۿ])/g }],
}
```

**٢.** أضفه إلى المصفوفة في `packages/core/src/dialects/index.ts`.

بطاقة الاختيار في الواجهة، وإعداد المحرك، وقوائم التنظيف — كلها تُشتق تلقائيًا.
لا يوجد أي شرط على مُعرّف لهجة في أي مكان آخر من الكود.

## تبديل محرك التفريغ

نفّذ واجهة `TranscriptionProvider` في `apps/gateway/src/providers/` وسجّله في
`createProvider()`، ثم اضبط `STT_PROVIDER`. بقية المشروع لا تعرف أي محرك يعمل خلفها.

**لماذا Speechmatics؟** نموذجه العربي الواحد مُدرَّب على الخليجي والمصري والشامي
والمغاربي معًا ويدعم خلط العربي/الإنجليزي داخل الجملة، بينما تعتمد بدائله على رموز
لهجات منفصلة تميل مخرجاتها إلى الفصحى. تكلفته للبث الحي أقل بنحو ثلاثة أضعاف من
Google، ويمنح 480 دقيقة مجانية شهريًا.

## طبقة التنظيف

سلسلة دوال نقية في `packages/core/src/cleaning/`:

| الخطوة            | ماذا تفعل                                          |
| ----------------- | -------------------------------------------------- |
| `normalizeArabic` | حذف التطويل والتشكيل، توحيد الأرقام، تصحيح الهمزات |
| `stripFillers`    | حذف الحشو مع تحمّل المدّ واستثناءات سياقية         |
| `collapseRepeats` | طيّ التلعثم ومدّ الحروف                            |
| `segmentByPause`  | تحويل الصمت الطويل إلى فواصل فقرات                 |
| `fixPunctuation`  | تنظيف آثار الحذف وضبط الترقيم العربي               |

مبدآن حاكمان:

1. **لا نحذف إلا ما لا يحمل معنى إطلاقًا.** «يعني» تُحذف في «يعني أنا رحت» وتبقى في
   «هذا يعني أن الأمر انتهى». و«ايه» المصرية محميّة في سياق الاستفهام. كلمات مثل
   «طيب» و«ماشي» و«like» لم تُدرج أصلًا رغم شيوعها كحشو.
2. **النص الخام لا يُتلف أبدًا.** كل مقطع يحفظ `raw` و`clean` معًا وقائمة ما حُذف،
   والواجهة فيها مفتاح تبديل بين العرضين.
